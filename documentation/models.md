# Models

Code Review runs distilled, instruction-tuned large language models.

> **💡** Knowledge distillation transfers knowledge from a large teacher model to a smaller student model and has become a widely adopted approach for model compression. However, a key challenge is the gap between the teacher and student models, which can lead to issues such as capacity mismatch, mode averaging, and mode collapse during distillation. [Temporally Adaptive Interpolated Distillation (TAID)](./taid.md) is a knowledge distillation approach designed to address these challenges.
